GPT-3 was not primarily an architectural innovation. It was a large-scale test of the scaling hypothesis.

Researchers asked whether sufficiently large language models could perform tasks directly from prompts rather than requiring task-specific fine-tuning.

GPT-3 was evaluated using:

Zero-shot:
Instruction only

One-shot:
One example in the prompt

Few-shot:
Several examples in the prompt

Performance improved significantly as the model was given examples, despite no weight updates occurring.

This demonstrated strong in-context learning capabilities and suggested that large language models can adapt behavior using information present in the prompt.

GPT-3 shifted the field from:

Pretrain → Fine-tune

toward:

Pretrain → Prompt

and established prompting as a practical way to use language models.
