Memory Systems - Part 3

Memory Lifecycle & Updating

Core Question:

Once memory exists,

how does it change over time?

---

Key Insight:

Memory is not static storage.

Memory is a living system.

---

Memory Lifecycle Stages

1. Creation

Information enters memory.

Example:

Alice lives in Paris.

---

2. Strengthening

Repeated evidence increases confidence.

Example:

Alice likes coffee appears multiple times.

Memory becomes stronger.

---

3. Updating

New information may replace old information.

Example:

Alice lives in Paris.

↓

Alice moved to London.

Memory must update.

---

Challenge:

Detect whether new information is:

A new fact

or

A replacement of an old fact.

---

4. Merging

Multiple related memories can be consolidated.

Example:

Alice likes coffee.

Alice prefers espresso.

Alice visits coffee shops.

↓

Alice is a coffee enthusiast.

---

5. Forgetting

Not all memories should survive forever.

Memory must remove low-value information.

---

Forgetting is necessary for scalability.

---

Human Analogy:

Brains constantly:

Create

Strengthen

Update

Merge

Forget

memories.

---

Researchers realized AI memory systems require the same lifecycle.

---

Main Insight:

Creating memory is easy.

Maintaining memory quality over time is the difficult problem.
